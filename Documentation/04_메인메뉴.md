# 메인 메뉴 (MainMenu)

## 한 줄 요약

`MainMenu` 씬은 **게임 선택·4인 로비·라운드 시작**을 담당하는 부스 운영 허브다. 플레이어는 패드 **START**로 참가·준비하고, 운영자는 키보드로 목록 이동·게임 시작을 제어한다. 현재 **실제 플레이 가능한 미니게임은 OIIA 하나**이며, 나머지 목록 항목은 카탈로그 플레이스홀더다.

---

## 화면 구성 (UI)

스크린샷 기준 레이아웃은 **다크 모드 와이어프레임** 단계다. 아이콘·애니메이션·일러스트 없이 **TextMeshPro 텍스트 + 단색 패널**로 구성되어 관전자·운영자가 상태를 빠르게 읽는 것을 우선한다.

```text
┌─────────────────────────────────────────────────────────────┐
│  [게임 목록 — 좌 45%]  │  [상세 설명 — 우 55%]              │
│  CarouselRow × 7       │  TMP_DetailTitle                   │
│  (세로 캐러셀)         │  TMP_DetailBody                    │
│                        │                                    │
├────────────────────────┴────────────────────────────────────┤
│  PLAYER 1  │  PLAYER 2  │  PLAYER 3  │  PLAYER 4            │
│  (상태)    │  (상태)    │  (상태)    │  (상태)              │
│  WIN n     │  WIN n     │  WIN n     │  WIN n               │
└─────────────────────────────────────────────────────────────┘
```

### 영역별 설명

| 영역 | 씬 오브젝트 | 역할 |
|------|-------------|------|
| 전체 배경 | `Panel_RootFull` | 검정 반투명(`alpha ≈ 0.91`) 풀스크린 |
| 중앙 컨테이너 | `Panel_CenterMenus` | 좌·우 패널을 묶는 영역. 세로 구분선 역할의 반투명 배경(`alpha ≈ 0.26`) |
| 게임 목록 (좌) | `Panel_GameList_Left` | 화면 좌측 **45%**, 세로 **7줄** 게임명 표시 |
| 게임 상세 (우) | `Panel_GameList_Right` | 선택 게임 **제목·설명** (`TMP_DetailTitle`, `TMP_DetailBody`) |
| 플레이어 HUD (하단) | `Panel_SlotHud_TopLeft` ~ `BottomRight` | 4분할 하단 바. 슬롯당 3줄 TMP |
| 결과 오버레이 | `Panel_Result` | 레거시 텍스트 결과창. **Results 씬 경유 복귀 시에는 표시하지 않음** |
| UI 루트 | `Canvas_Menu` | Screen Space Overlay 캔버스 |
| 시스템 | `GameSystems` | `GameFlowDirector` + `PartySession` 참조 |

### 게임 목록 (캐러셀)

- **표시 줄 수**: 7 (`CarouselRow_00` ~ `_06`).
- **선택 위치**: 가운데 줄(`CenterRow = 3`, `CarouselRow_03`).
- **선택 표시**: 가운데 행 제목을 `[ OIIA (Rhythm / Sustain) ]` 형태로 **대괄호** 감싸기 (`RefreshMenuUi`).
- **스크롤**: 위·아래로 이동하면 목록이 **순환(wrap)** 하며, 보이는 7줄 전체가 갱신된다.
- **항목 수**: 카탈로그 기본 **8개** (OIIA 1 + TBD 7). 7줄 창에 8개 전체가 동시에 보이지는 않고, 스크롤로 순환한다.

### 상세 패널 (우측)

선택된 `GameCatalogEntry`의 `title`·`blurb`를 표시한다. OIIA 기본값 예:

- **제목**: `OIIA (Rhythm / Sustain)`
- **본문**:
  - `X = O, A = I, Y = A`
  - `Repeat pattern: oiiaiooiiiai.`
  - `Fail FX and rising difficulty.`

### 플레이어 슬롯 HUD (하단 4칸)

각 슬롯(`SL1`~`SL4`)은 동일한 3줄 구조다.

| 줄 | 필드 | 내용 |
|----|------|------|
| Line1 | 고정 | `PLAYER 1` ~ `PLAYER 4` |
| Line2 | 상태별 | 아래 「슬롯 상태·색」 참고 |
| Line3 | 연승 | `WIN {WinStreak}` |

**Line2 상태·색 (`FlushSlotHudRow`)**

| `SlotState` | 문구 | 색·연출 |
|-------------|------|---------|
| `EMPTY` | `PRESS START TO JOIN` | 흰색, **알파 펄스** (0.1 ↔ 1.0, 속도 3.6) |
| `ACTIVE` | `PRESS START TO READY` | **#FFCD00**, 동일 펄스 |
| `READY` | `READY` | 녹색 `(0.25, 0.92, 0.42)` 고정 |
| `PLAYING` | `PLAY` | 흰색 |
| `RESULT` | `RESULT` | 흰색 |
| `GAMEOVER` | `GAME OVER` | 흰색 |

Line3 `WIN` 카운터는 **세션 연승**을 나타낸다. 본게임 Result에서 HP를 잃지 않았을 때 `IncrementWinStreak()`으로 증가한다.

## 입력

### 운영자 (키보드)

| 입력 | 동작 |
|------|------|
| `↑` | 게임 목록 **위**로 (순환) |
| `↓` | 게임 목록 **아래**로 (순환) |
| `Enter` / 키패드 Enter | **전원 READY**일 때 선택 게임 시작 |

`OperatorInputService`는 **새 Input System**과 **레거시 `UnityEngine.Input`** 을 모두 확인한다.

### 플레이어 (패드, 슬롯 0~3)

| 슬롯 상태 | START |
|-----------|-------|
| `EMPTY` | **JOIN** — HP를 `PartySession.StartingHp`로 설정, `WinStreak = 0`, `ACTIVE` |
| `ACTIVE` | **READY** 토글 |
| `READY` | **ACTIVE**로 되돌리기 (토글) |

**게임 중·Result 씬 중에는 JOIN 불가.** `EMPTY → ACTIVE` 전환은 메인 메뉴(`TickMenuLobby`)에서만 허용된다.

### 시작 조건 (`CanStartFromMenu`)

- **한 명이라도 `ACTIVE`만** 있으면 Enter **불가** → 참가 중인 모든 슬롯이 **`READY`** 여야 한다.
- **최소 1명 `READY`** 필요.

## 플레이어 플로우

```text
[메인] EMPTY ──START──► ACTIVE ──START──► READY
                              ▲              │
                              └── START ─────┘ (토글)

[운영자 Enter, 전원 READY]
        │
        ▼
[Oiia 씬] 연습(기본) ──(연습 종료 후 큐)──► 본게임 1회
        │
        ▼
[Results 씬] 등수·HP·GAME OVER 연출
        │
        ▼ (운영자 Enter, FinalizeLobbyAfterMinigame)
[메인 복귀]
  · HP > 0  → ACTIVE (재-JOIN 없이 START로 READY 가능)
  · HP ≤ 0  → EMPTY (PRESS START TO JOIN)
  · HP 미감소 → WIN streak +1
```

### Oiia 연습 → 본게임 큐

- 메뉴에서 Enter로 진입하면 **기본 연습 라운드** (`TakeOiiaNextRoundIsPractice()` → `true`).
- 연습 종료 후 `PartySession.QueueOiiaMainRoundAfterPracticeEnded()` — **다음 Enter는 본게임 1회**.
- 본게임 종료 후 `ResetOiiaCycleAfterMainSession()` — 다시 **연습부터** 시작.

### Results 씬 경유 vs 레거시

| 복귀 경로 | 메인에서의 동작 |
|-----------|-----------------|
| **Results 씬** (`TryConsumePostResultReport`) | `Panel_Result` **숨김**. 로비 상태는 Result 종료 시 이미 `FinalizeLobbyAfterMinigame` 적용됨 |
| **레거시 직통** (`TryConsumePendingReport`) | `Panel_Result` 텍스트 오버레이 표시 → Enter로 닫기 |

현재 정상 플로우는 **Results 씬 경유**가 기본이다.

## 게임 카탈로그

`GameFlowDirector` Inspector의 `catalog` 배열, 또는 비어 있을 때 코드 **폴백** (`EnsureCatalogPopulatedFallback`).

| id | title | 구현 |
|----|-------|------|
| `oiia` | OIIA (Rhythm / Sustain) | **구현됨** → `Minigame_O.I.I.A.` |
| `rhythm_button_challenge` | Rhythm Button Challenge | **구현됨** → `Minigame_RhythmButtonChallenge` |
| `coffin_dance` | 관짝춤 | **C# 완료** · 씬 `Minigame_CoffinDance` 조립·Build 후속 · blurb 추후 |
| `placeholder_04` ~ `_08` | GAME 04~08 (TBD) | **미구현** |

### 게임 시작 라우팅 (`StartSelectedMinigame`)

```text
debugRouteAllToOiia == true  OR  entry.id == "oiia"
  → oiiaSceneName

entry.id == "rhythm_button_challenge"
  → rhythmButtonChallengeSceneName

entry.id == "coffin_dance"
  → coffinDanceSceneName ("Minigame_CoffinDance") · 연습 큐 TakeCoffinDanceNextRoundIsPractice

그 외
  → detailBody "not available yet"
```

**현재 씬 설정**: `debugRouteAllToOiia = false`(2026-07-22 기준). 카탈로그 id별 씬 분기.

시작 시 `menuCanvas`를 **비활성화**한 뒤 미니게임 씬을 Single 모드로 로드한다.

## 구현 진행도

| 영역 | 상태 | 비고 |
|------|------|------|
| 3단 레이아웃 (목록 / 상세 / 슬롯 HUD) | **완료** | TMP + Image 패널, 프리팹화 없음 |
| 7줄 순환 캐러셀 | **완료** | `RefreshMenuUi`, wrap 스크롤 |
| 4슬롯 JOIN · READY | **완료** | `PlayerSlotModel` + `TickMenuLobby` |
| 운영자 메뉴·시작 | **완료** | `OperatorInputService` |
| OIIA 씬 로드 | **완료** | `SceneManager.LoadScene(oiiaSceneName)` |
| Results 복귀·연속 플레이 | **완료** | 생존 `ACTIVE` 유지, 탈락 `EMPTY` |
| WIN streak 표시 | **완료** | Line3 |
| 다중 미니게임 카탈로그 | **미구현** | placeholder만, id별 씬 분기 없음 |
| `debugRouteAllToOiia` | **MVP 임시** | true면 전 항목 → OIIA |
| 선택 항목 **색상** 강조 | **부분** | 코드는 **대괄호**만. 노란색(#FFCD00)은 슬롯 ACTIVE Line2에만 적용 |
| UI 폴리시 (아이콘·BGM·전환 연출) | **미착수** | 와이어프레임 수준 |
| `Panel_Result` 레거시 오버레이 | **유지** | Results 경로에서는 사용 안 함 |

**UI 성숙도**: 기능 검증용 **프로토타입**. 부스 운영에 필요한 **정보 전달·입력**은 동작하지만, 비주얼·사운드·브랜딩 연출은 후속 작업 대상이다.

## 알려진 한계·후속 작업

1. **카탈로그 placeholder** — GAME 02~08은 목록·설명만 있고 씬·모듈 없음.
2. **`debugRouteAllToOiia`** — 다중 게임 출시 전 **false**로 두고 id별 씬 매핑 필요.
3. **선택 항목 시각 강조** — 대괄호 외 색·크기·사운드 미적용 (기획 톤 #FFCD00는 슬롯 ACTIVE에 사용 중).
4. **UI 에셋** — 슬롯·목록 공통 프리팹 없음. 씬에 TMP 7+4×3개 직접 배치.
5. **카탈로그 Inspector 편집** — 씬에서 `catalog: []`이면 런타임 폴백만 사용. 기획 데이터를 씬/ScriptableObject로 옮기면 에디터에서 항목 편집 가능.

### 새 미니게임 추가 시 메인 메뉴 작업

1. `GameCatalogEntry`에 `id`, `title`, `blurb` 등록.
2. `StartSelectedMinigame`에 id → 씬 이름 분기 추가.
3. `debugRouteAllToOiia` 비활성화 또는 제거.
4. (선택) 상세 패널용 아이콘·스크린샷 UI 확장.
