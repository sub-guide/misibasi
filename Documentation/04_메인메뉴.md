# 메인 메뉴 (MainMenu)

## 한 줄 요약

`MainMenu` 씬은 **4인 로비·카탈로그 선택·라운드 시작**을 담당하는 부스 운영 허브다. 화면은 **좌 65% / 우 35% / 하단 20%** (`Panel_Left` · `Panel_Right` · `Slot_Player`). 목록 비주얼(릴)은 아직 없고, ↑/↓는 우측 TMP만 갱신한다.

---

## 화면 구성 (UI)

스크린샷 기준이 아니라 **현재 씬 Hierarchy**다.

```text
Canvas
├── Panel_Left          (x 0~0.65, y 0.2~1)   목록·릴 자리, 자식 없음
├── Panel_Right         (x 0.65~1, y 0.2~1)   TMP_DetailTitle / TMP_DetailBody
└── Slot_Player         (y 0~0.2, 가로 전체)
    ├── Slot_Player_1
    ├── Slot_Player_2
    ├── Slot_Player_3
    └── Slot_Player_4

GameSystems, PartySession, Main Camera, EventSystem
```

### 영역별 설명

| 영역 | 씬 오브젝트 | 역할 |
|------|-------------|------|
| UI 루트 | `Canvas` | Screen Space Overlay (`menuCanvas`) |
| 좌 65% | `Panel_Left` | 릴/목록용. 비어 있음 |
| 우 35% | `Panel_Right` | `TMP_DetailTitle`, `TMP_DetailBody` |
| 하단 20% | `Slot_Player` | 프리팹 `Assets/Mainmenu/Prefabs/Slot_Player.prefab` ×4 (`Slot_Player_1`~`_4`) |
| 시스템 | `GameSystems` | `GameFlowDirector` |
| 세션 | `PartySession` | DontDestroyOnLoad |

### 게임 목록 (현재)

목록 **비주얼은 없음**. ↑/↓는 `_selectedCatalogIndex`만 wrap하고 우측 TMP를 갱신한다. `MainMenuReelController` / `ReelColumn` / `ReelSymbolView` C#은 컴파일용으로 **남아 있으나 씬에서 쓰지 않음**. 재도입은 설계 잠금 후.

### 상세 패널 (우측)

선택된 `GameCatalogEntry`의 `title`·`blurb`. 필드: `id`, `title`, `blurb`, `icon`, `accentColor`.

- **제목**: `OIIA (Rhythm / Sustain)`
- **본문**:
  - `X = O, A = I, Y = A`
  - `Repeat pattern: oiiaiooiiiai.`
  - `Fail FX and rising difficulty.`

### 플레이어 슬롯 HUD (하단 4칸)

각 슬롯은 프리팹 자식 `SL1_Line1` / `SL1_Line2` / `SL1_Line3` (이름은 1P 프리팹 그대로). `GameFlowDirector.slotHud[0]`만 연결됨. `[1]`~`[3]`은 **None** — 2P~4P TMP를 드래그해야 한다.

| 줄 | 필드 | 내용 |
|----|------|------|
| Line1 | 고정 | `PLAYER 1` ~ `PLAYER 4` |
| Line2 | 상태별 | 아래 「슬롯 상태·색」 참고 |
| Line3 | 연승 | `WIN {WinStreak}` |

**Line2 상태·색 (`FlushSlotHudRow`)**

| `SlotState` | 문구 | 색·연출 |
|-------------|------|---------|
| `EMPTY` | `PRESS START TO JOIN` | 흰색, **알파 펄스** (0.1 ↔ 1.0, 속도 3.6) |
| `ACTIVE` | `PRESS START TO READY` | **#FFCD00**, 동일 펄스 |
| `READY` | `READY` | 녹색 `(0.25, 0.92, 0.42)` 고정 |
| `PLAYING` | `PLAY` | 흰색 |
| `RESULT` | `RESULT` | 흰색 |
| `GAMEOVER` | `GAME OVER` | 흰색 |

Line3 `WIN` 카운터는 **세션 연승**을 나타낸다. 본게임 Result에서 HP를 잃지 않았을 때 `IncrementWinStreak()`으로 증가한다.

## 입력

### 운영자 (키보드)

| 입력 | 동작 |
|------|------|
| `↑` | 카탈로그 인덱스 **위** (순환). 우측 TMP만 갱신 |
| `↓` | 카탈로그 인덱스 **아래** (순환) |
| `Enter` / 키패드 Enter | **전원 READY**일 때 선택 게임 시작 |

`OperatorInputService`는 **새 Input System**과 **레거시 `UnityEngine.Input`** 을 모두 확인한다.

### 플레이어 (패드, 슬롯 0~3)

| 슬롯 상태 | START |
|-----------|-------|
| `EMPTY` | **JOIN** — HP를 `PartySession.StartingHp`로 설정, `WinStreak = 0`, `ACTIVE` |
| `ACTIVE` | **READY** 토글 |
| `READY` | **ACTIVE**로 되돌리기 (토글) |

**게임 중·Result 씬 중에는 JOIN 불가.** `EMPTY → ACTIVE` 전환은 메인 메뉴(`TickMenuLobby`)에서만 허용된다.

### 시작 조건 (`CanStartFromMenu`)

- **한 명이라도 `ACTIVE`만** 있으면 Enter **불가** → 참가 중인 모든 슬롯이 **`READY`** 여야 한다.
- **최소 1명 `READY`** 필요.

## 플레이어 플로우

```text
[메인] EMPTY ──START──► ACTIVE ──START──► READY
                              ▲              │
                              └── START ─────┘ (토글)

[운영자 Enter, 전원 READY]
        │
        ▼
[Oiia 씬] 연습(기본) ──(연습 종료 후 큐)──► 본게임 1회
        │
        ▼
[Results 씬] 등수·HP·GAME OVER 연출
        │
        ▼ (운영자 Enter, FinalizeLobbyAfterMinigame)
[메인 복귀]
  · HP > 0  → ACTIVE (재-JOIN 없이 START로 READY 가능)
  · HP ≤ 0  → EMPTY (PRESS START TO JOIN)
  · HP 미감소 → WIN streak +1
```

### Oiia 연습 → 본게임 큐

- 메뉴에서 Enter로 진입하면 **기본 연습 라운드** (`TakeOiiaNextRoundIsPractice()` → `true`).
- 연습 종료 후 `PartySession.QueueOiiaMainRoundAfterPracticeEnded()` — **다음 Enter는 본게임 1회**.
- 본게임 종료 후 `ResetOiiaCycleAfterMainSession()` — 다시 **연습부터** 시작.

### Results 복귀

| 복귀 경로 | 메인에서의 동작 |
|-----------|-----------------|
| **Results 씬** (`TryConsumePostResultReport`) | 로비만 복구. 메인 오버레이 없음 |
| **레거시 직통** (`TryConsumePendingReport`) | `FinalizeLobbyAfterMinigame`만. 텍스트 결과창 **없음** |

정상 플로우는 **Results 씬 경유**.

## 게임 카탈로그

`GameFlowDirector` Inspector의 `catalog` 배열, 또는 비어 있을 때 코드 **폴백** (`EnsureCatalogPopulatedFallback`).

| id | title | 구현 |
|----|-------|------|
| `oiia` | OIIA (Rhythm / Sustain) | **구현됨** → `Minigame_O.I.I.A.` |
| `rhythm_button_challenge` | Rhythm Button Challenge | **구현됨** → `Minigame_RhythmButtonChallenge` |
| `coffin_dance` | 관짝춤 | **C# 완료** · 씬 `Minigame_CoffinDance` 조립·Build 후속 · blurb 추후 |
| `placeholder_04` ~ `_08` | GAME 04~08 (TBD) | **미구현** |

### 게임 시작 라우팅 (`StartSelectedMinigame`)

```text
debugRouteAllToOiia == true  OR  entry.id == "oiia"
  → oiiaSceneName

entry.id == "rhythm_button_challenge"
  → rhythmButtonChallengeSceneName

entry.id == "coffin_dance"
  → coffinDanceSceneName ("Minigame_CoffinDance") · 연습 큐 TakeCoffinDanceNextRoundIsPractice

그 외
  → detailBody "not available yet"
```

**현재 씬 설정**: `debugRouteAllToOiia = false`(2026-07-22 기준). 카탈로그 id별 씬 분기.

시작 시 `menuCanvas`를 **비활성화**한 뒤 미니게임 씬을 Single 모드로 로드한다.

## 구현 진행도

| 영역 | 상태 | 비고 |
|------|------|------|
| 로비 JOIN · READY · Enter | **완료** | `TickMenuLobby` |
| 화면 분할 65:35 + 하단 20% | **에디터 완료** | `Panel_Left` / `Panel_Right` / `Slot_Player` |
| 카탈로그 ↑/↓ (TMP 상세만) | **완료** | `Panel_Left` 비주얼 없음 |
| `slotHud` 2P~4P | **미연결** | Element 1~3 None |
| 릴·포커 HUD·셔플 | **미착수** | 설계 남은 항목 |

**UI 성숙도**: 기능 검증용 **프로토타입**. 부스 운영에 필요한 **정보 전달·입력**은 동작하지만, 비주얼·사운드·브랜딩 연출은 후속 작업 대상이다.

## 코드 ↔ UI 바인딩

| SerializeField | 씬 오브젝트 |
|----------------|-------------|
| `menuCanvas` | `Canvas` |
