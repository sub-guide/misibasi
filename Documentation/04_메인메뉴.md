# 메인 메뉴 (MainMenu)

## 한 줄 요약

`MainMenu` 씬은 **4인 로비·카탈로그 선택·라운드 시작**을 담당하는 부스 운영 허브다. 화면은 **좌 65% / 우 35% / 하단 20%** (`Panel_Left` · `Panel_Right` · `Slot_Player`). 하단은 포커 카드 HUD(`SlotPokerHud`). 좌측은 3릴(`Reel_0`~`Reel_2`). ↑/↓는 wrap + `PlayStep`. Space는 인덱스 추첨 후 `PlaySpin`(시차 정차).

---

## 화면 구성 (UI)

스크린샷 기준이 아니라 **현재 씬 Hierarchy**다.

```text
Canvas
├── Panel_Left          (x 0~0.65, y 0.2~1)
│   └── Reel_Range
│       ├── Reel_0      (prefab Reel, 프리팹 루트명 Reel)
│       ├── Reel_1
│       └── Reel_2
├── Panel_Right         (x 0.65~1, y 0.2~1)   TMP_DetailTitle / TMP_DetailBody
└── Slot_Player         (y 0~0.2, 가로 전체)
    ├── Slot_Player_1
    ├── Slot_Player_2
    ├── Slot_Player_3
    └── Slot_Player_4

GameSystems, PartySession, Main Camera, EventSystem
```

### 영역별 설명

| 영역 | 씬 오브젝트 | 역할 |
|------|-------------|------|
| UI 루트 | `Canvas` | Screen Space Overlay (`menuCanvas`) |
| 좌 65% | `Panel_Left` → `Reel_Range` | `Reel_0`~`Reel_2` (프리팹 `Assets/Mainmenu/Prefabs/Reel.prefab`). 컬럼당 `Symbol_0`~`4` Y 600/300/0/−300/−600. ±600은 마스크 밖 Recycle |
| 우 35% | `Panel_Right` | `TMP_DetailTitle`, `TMP_DetailBody` |
| 하단 20% | `Slot_Player` | 프리팹 `Assets/Mainmenu/Prefabs/Slot_Player.prefab` ×4 (`Slot_Player_1`~`_4`) |
| 시스템 | `GameSystems` | `GameFlowDirector` |
| 세션 | `PartySession` | DontDestroyOnLoad |

### 게임 목록 (현재)

세 컬럼이 **같은 카탈로그 인덱스**를 보여 준다. `MainMenuReelController`가 `bounceCurve`로 한 칸 이동, `ReelColumn`이 에디터 심볼만 Recycle(Instantiate 없음). 중앙(y≈0)만 `accentColor`, 나머지는 `silhouetteColor`. 크기·알파는 건드리지 않는다. ↑/↓ 중 `lockInputUntilSettled`이면 다음 칸은 착지 후. **↑/↓ 릴 1차 Play 확인**(2026-09-03).

**Space:** Director가 `Random.Range`로 인덱스 1개(현재와 같아도 됨) → 우측 TMP 빈 문자열 → `PlaySpin`. **시작은 지금 가운데 그림 그대로**, 세 줄 **같은 속도**. 가속 → 크루즈(전부 실루엣) → 정차는 아래 방향만. 칸 안 그림은 ↑/↓와 같이 **다음 인덱스 + 남은 오프셋**(`LayoutFromTravel`). 추가 바퀴는 최고속, 남은 거리가 감속 구간이면 `decelDuration`·`spinDecelCurve`로 줄임. 당첨을 지나쳤으면 한 바퀴 더. 줄마다 카탈로그를 `extraLoopsPerColumn`바퀴씩 더 가서 시차(`Reel_0` 0, `Reel_1` 2, `Reel_2` 4. 기본 2). 도는 줄은 실루엣, 멈춘 줄만 가운데 컬러. 정차 후 TMP 복구. 스핀·바운스 중 ↑↓/Space/Enter 무시. JOIN/READY는 유지.

### 상세 패널 (우측)

선택된 `GameCatalogEntry`의 `title`·`blurb`. 필드: `id`, `title`, `blurb`, `icon`, `accentColor`.

- **제목**: `OIIA (Rhythm / Sustain)`
- **본문**:
  - `X = O, A = I, Y = A`
  - `Repeat pattern: oiiaiooiiiai.`
  - `Fail FX and rising difficulty.`

### 플레이어 슬롯 HUD (하단 4칸)

TMP `SL1_Line1`~`3`는 **사용하지 않음**(프리팹에서 비활성). Canvas 2D 카드 HUD. 스크립트 `SlotPokerHud`. `GameFlowDirector.slotPokerHud[0]`~`[3]`에 각 `Slot_Player_1`~`_4`. **JOIN/READY 카드 애니 Play 확인됨**(2026-08-31).

입력 상태머신(`EMPTY`→`ACTIVE`↔`READY`)은 기존과 같다. HP 0 EMPTY에서도 Start로 **재JOIN 가능**.

| 비주얼 | 조건 | 연출 |
|--------|------|------|
| 딤 | `EMPTY` 이고 `HP > 0` | `dimOverlay` 활성. 카드 Hidden |
| 암전 | `HP ≤ 0` | `blackoutOverlay` 활성. 카드 Hidden. Start 잠금 없음 |
| 부채꼴 `Fan` | 남은 HP 장 | 테두리 **위**. Animator `Mode=1`. 클립에서 떠오름·루프 |
| 뒷면 `FaceDown` | 잃은 장 `L = StartingHp - HP` | 테두리 `landPads[0 .. L-1]` 왼쪽부터. `Mode=2`, `Pad=i` |
| 착지 `Slam` | `READY` (및 PLAYING/RESULT) 이고 HP≥1 | 다음 빈 칸 `landPads[L]`에 앞면 1장. `Mode=3` |

Animator Int 파라미터: `Mode` (0 Hidden, 1 Fan, 2 FaceDown, 3 Slam), `Pad` (0 왼쪽, 1 오른쪽). 위치·각도는 **클립**. `Card_0`은 `SlotPokerCard`. `Card_1`은 **Animator Override Controller** `SlotPokerCard_Right`. `FaceDown`/`Hidden`은 공유.

**연승 칩**: 수직 탑 없음. 1연승당 1장, 표시 최대 `streakChips.Length`(5). Inspector `[0]`=오른쪽 `Chip_1`, `[1]`=그 왼쪽 `Chip_2` … `[4]`=`Chip_5`. `EMPTY`·HP≤0·연승 0이면 전부 끔. 6연승 이상은 5장만. 스프라이트 `Assets/Mainmenu/Sprites/Chips.png` 슬라이스 `Chip_1`~`Chip_5`. 배치는 에디터, 코드는 `SetActive`.

에셋: 앞면 `Assets/Mainmenu/Sprites/Cards/card fronts/hearts/ace of hearts.png`, 뒷면 `card backs/card back red.png`, 테두리 `Cards/card_outline.png` ×2(가로).

## 입력

### 운영자 (키보드)

| 입력 | 동작 |
|------|------|
| `↑` | 카탈로그 인덱스 **위** (순환). `reel.PlayStep` + 우측 TMP |
| `↓` | 카탈로그 인덱스 **아래** (순환). 동일 |
| `Space` | 무작위 추첨 + `PlaySpin`. 스핀 중 재입력 무시 |
| `Enter` / 키패드 Enter | **전원 READY**일 때 선택 게임 시작. 스핀 중 무시 |

`OperatorInputService`는 **새 Input System**과 **레거시 `UnityEngine.Input`** 을 모두 확인한다.

### 플레이어 (패드, 슬롯 0~3)

| 슬롯 상태 | START |
|-----------|-------|
| `EMPTY` | **JOIN** — HP를 `PartySession.StartingHp`로 설정, `WinStreak = 0`, `ACTIVE` |
| `ACTIVE` | **READY** 토글 |
| `READY` | **ACTIVE**로 되돌리기 (토글) |

**게임 중·Result 씬 중에는 JOIN 불가.** `EMPTY → ACTIVE` 전환은 메인 메뉴(`TickMenuLobby`)에서만 허용된다.

### 시작 조건 (`CanStartFromMenu`)

- **한 명이라도 `ACTIVE`만** 있으면 Enter **불가** → 참가 중인 모든 슬롯이 **`READY`** 여야 한다.
- **최소 1명 `READY`** 필요.

## 플레이어 플로우

```text
[메인] EMPTY ──START──► ACTIVE ──START──► READY
                              ▲              │
                              └── START ─────┘ (토글)

[운영자 Enter, 전원 READY]
        │
        ▼
[Oiia 씬] 연습(기본) ──(연습 종료 후 큐)──► 본게임 1회
        │
        ▼
[Results 씬] 등수·HP·GAME OVER 연출
        │
        ▼ (운영자 Enter, FinalizeLobbyAfterMinigame)
[메인 복귀]
  · HP > 0  → ACTIVE (재-JOIN 없이 START로 READY 가능)
  · HP ≤ 0  → EMPTY (PRESS START TO JOIN)
  · HP 미감소 → WIN streak +1
```

### Oiia 연습 → 본게임 큐

- 메뉴에서 Enter로 진입하면 **기본 연습 라운드** (`TakeOiiaNextRoundIsPractice()` → `true`).
- 연습 종료 후 `PartySession.QueueOiiaMainRoundAfterPracticeEnded()` — **다음 Enter는 본게임 1회**.
- 본게임 종료 후 `ResetOiiaCycleAfterMainSession()` — 다시 **연습부터** 시작.

### Results 복귀

| 복귀 경로 | 메인에서의 동작 |
|-----------|-----------------|
| **Results 씬** (`TryConsumePostResultReport`) | 로비만 복구. 메인 오버레이 없음 |
| **레거시 직통** (`TryConsumePendingReport`) | `FinalizeLobbyAfterMinigame`만. 텍스트 결과창 **없음** |

정상 플로우는 **Results 씬 경유**.

## 구현 진행도

| 영역 | 상태 | 비고 |
|------|------|------|
| 로비 JOIN · READY · Enter | **완료** | `TickMenuLobby` (HP 0 재JOIN 유지) |
| 화면 분할 65:35 + 하단 20% | **에디터 완료** | `Panel_Left` / `Panel_Right` / `Slot_Player` |
| 카탈로그 ↑/↓ | **Play 확인** | wrap + TMP + 3릴 동기 |
| 포커 카드 HUD C# | **코드 완료** | `SlotPokerHud` · `slotPokerHud` |
| 카드 프리팹·Animator·Override | **에디터 완료** · **Play 확인** | `Card_1` → `SlotPokerCard_Right` (`Assets/Mainmenu/Animation/`) |
| 칩 HUD | **에디터 완료** · **Play 확인** | `streakChips` 가로 1장·최대 5 |

**UI 성숙도**: 기능 검증용 **프로토타입**. 부스 운영에 필요한 **정보 전달·입력**은 동작하지만, 비주얼·사운드·브랜딩 연출은 후속 작업 대상이다.

## 알려진 한계·후속 작업

1. **카탈로그** — 씬은 구현 3종(OIIA·리듬 챌린지·관짝춤). 추가 게임은 후속.
2. **`debugRouteAllToOiia`** — 출시 전 false 유지, id별 씬 매핑.
3. **릴 Space** — C# 완료. Play 검증 후속. 암전 Image·스팟 없음.
4. **하단 HUD** — 카드·연승 칩 **Play 확인**. 수직 탑 없음.

### 새 미니게임 추가 시 메인 메뉴 작업

1. `GameCatalogEntry`에 `id`, `title`, `blurb` (및 아이콘이 필요하면 `icon`/`accentColor`) 등록.
2. `StartSelectedMinigame`에 id → 씬 이름 분기 추가.
3. `debugRouteAllToOiia`는 false로 둔다.
